# @ninjavault/cdn 100.43.0

Date: 2026-11-05
Type: Minor

## Changes
- `UploadRequest.tenantId` and `FileListQuery.tenantId` are typed `string` (the tenant GUID) instead of
  `string | number | bigint`. Tenant ids read from the API (`FileObject.tenantId`, `AccessContext.allowedTenantIds`)
  were already strings and stay that way.
- Plain-JavaScript callers that still pass a number or bigint keep working at runtime; the value is sent as text.
- README examples use GUID tenant ids.

## Why
- The NinjaVault CDN server switched tenant ids from numeric ids to GUIDs. One type (`string`) for every tenant id
  matches the server and the .NET (`NinjaVault.Cdn`) and Python (`ninjavault-cdn`) 100.43.0 packages.

## Breaking Changes
- TypeScript code that passes `tenantId` as a number or bigint no longer type-checks. Pass the tenant id as a string.
